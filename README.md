# 最低賃金算定ツール

賃金が地域別最低賃金を満たしているか判定するWebツールです。

## 概要

従業員の賃金を入力し、選択した都道府県の最低賃金と比較して「適合」「不足」を判定します。単一HTMLファイルで動作し、サーバー不要でブラウザのみで利用できます。

## 対応データ

- **令和7年度（2025年10月発効）** 地域別最低賃金 全47都道府県

## 機能

### 賃金形態

以下の5つの賃金形態に対応しています。

| 賃金形態 | 計算方法 |
|----------|----------|
| 時間給制 | 時間給 ≧ 最低賃金額 |
| 日給制 | 日給 ÷ 1日の所定労働時間 ≧ 最低賃金額 |
| 月給制 | (月給 − 除外賃金) ÷ 月平均所定労働時間 ≧ 最低賃金額 |
| 出来高払制 | 賃金総額 ÷ 総労働時間 ≧ 最低賃金額 |
| 組み合わせ | 各部分の時間換算額の合計 ≧ 最低賃金額 |

### 除外賃金

月給制・組み合わせ（月給部分）では、以下の除外賃金を控除して計算します。

- 精皆勤手当、通勤手当、家族手当
- 時間外・休日・深夜割増賃金
- 臨時に支払われる賃金、賞与等

### 来年度シミュレーション

来年度の予想最低賃金を入力して、現行との比較判定ができます。

- 現行と来年度予想の判定結果を並べて比較
- 不足時は月額換算の昇給目安を表示
- 現行比の引き上げ額・引き上げ率をリアルタイム表示

### 出力

- **CSV出力** : 判定結果をCSVファイルでダウンロード
- **印刷** : 判定結果を印刷用レイアウトで出力

## 使い方

`最低賃金算出ツール.html` をブラウザで開くだけで利用できます。

## 注意事項

- 特定（産業別）最低賃金は考慮していません
- 実際の適用については管轄の労働基準監督署にご確認ください
- 出典: [厚生労働省 地域別最低賃金の全国一覧](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/koyou_roudou/roudoukijun/minimumichiran/)
